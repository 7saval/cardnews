## 🐛 발생한 문제 & 해결

### 문제 1: `API access blocked` (subcode 5258005)로 인사이트 수집 7주 실패
- **원인**: 미확인. 토큰·권한·앱은 정상이었고, 확인 시점엔 이미 풀려 있었다
- **해결**: 범위 좁히기(토큰 디버거 → `me` → 계정 → insights)로 정상 확인 후 수동 실행으로 복구 확인
- **참고**: 다시 막히면 앱 대시보드 알림과 계정 상태부터. **실패 알림이 없어서 7주를 몰랐다** → 알림 필요

### 문제 2: 장기 토큰 재교환해도 만료일이 안 늘어남
- **원인**: Meta는 장기 토큰을 다시 교환해도 기존 만료일을 유지한다
- **해결**: Explorer에서 새 단기 토큰 발급 → 교환

### 문제 3: 로컬 Haiku 폴백이 401 `invalid x-api-key`
- **원인**: 로컬 `.env`의 키가 무효(형식은 정상). GitHub Secret은 10-29에 바뀐 다른 키라 Actions는 정상
- **해결**: Console에서 새 키 발급 → 로컬 `.env` 교체
- **참고**: 형식 점검 스크립트 버그(`slice(-0)`)로 무효 키 전체가 대화 기록에 출력됨 → Console에서 해당 키 삭제 권고. 비밀값 점검은 길이·접두사만 출력하고 슬라이스 인덱스를 다시 확인할 것

### 문제 4: Gemini 504/503로 매번 Haiku 폴백
- **원인**: Gemini 과부하 (오늘 3번 시도 모두 실패)
- **해결**: 폴백으로 생성은 됨. 미해결 — 계속되면 기본 프로바이더 교체 검토

### 문제 5: 해시태그 추가가 테스트를 통과했는데 실제 캡션엔 없음
- **원인**: Python 일괄 치환에서 `\n` 이스케이프가 어긋나 호출 줄과 그걸 검사하는 테스트 수정이 **둘 다** 조용히 실패
- **해결**: 결과 파일을 직접 보고 발견, Edit으로 수정
- **참고**: 치환 스크립트는 `assert old in s`로 매치를 확인하고, 테스트가 통과해도 산출물을 한 번은 눈으로 본다

### 문제 6: 문의 칸 전화번호가 "044-" / "202-7450"으로 끊김
- **해결**: 마지막 번호 토큰만 `white-space: nowrap`으로 감쌈 (`ContactText`)

## 💡 배운 점 / 메모

- fact-check는 **숫자만** 본다. "오프라인" 같은 숫자 없는 표현은 사람 검수가 잡아야 한다 → 새 필드를 늘릴수록 검수 포인트도 는다
- `actions/cache`의 7일 삭제 규칙은 주간 작업과 상극. 주기가 7일 이상이면 artifact나 저장소 커밋으로 넘긴다
- 보조금24 원문 필드는 `||`로 다중 값이 들어오고, "직접입력"처럼 의미 없는 값도 있다 → 표시용 정규화 함수 + 같은 함수로 검증
- 범위 좁히기 순서(토큰 → 기본 호출 → 계정 → 목표 엔드포인트)로 하면 Meta 에러를 몇 분 안에 계정/앱/권한 중 어디인지 가를 수 있다
