## ✅ 완료한 작업

### 1. 브랜드 로고 콘셉트 기획 및 4종 시안 생성

인스타그램 맛집 큐레이션 미디어 **'맛수집(Mat-Soojip)'**의 카드뉴스 우측 상단 배지(지름 130px) 규격에 맞춰 4가지 콘셉트의 고화질 배지 로고를 생성하고 아티팩트(`matsoojip_logo_designs.md`)로 비교 제공:

- **시안 1 (탐험가 곰 셰프)**: 스푼과 돋보기를 든 친근한 마스코트 스티커형
- **시안 2 (미식 아카이브 스탬프)**: 핀 + 포크 + 불꽃이 결합된 전문 매거진 엠블럼형
- **시안 3 (냠냠 캣 & 별점 수집가)**: 별(★)과 포크를 든 위트 있는 레트로 팝 키치형
- **시안 4 (클로슈 & 북마크)**: 김이 모락모락 나는 요리 클로슈와 저장 리본을 결합한 미니멀 모던 배지형
- 사용자가 **시안 4**로 최종 확정함.

### 2. 카드 렌더러 컴포넌트 및 CSS 연동

- [`CoverCard.tsx`](../../apps/card-renderer/src/components/CoverCard.tsx), [`ContentCard.tsx`](../../apps/card-renderer/src/components/ContentCard.tsx): `logoUrl` prop 지원 및 기본 로고 경로 지정
- [`FollowCTACard.tsx`](../../apps/card-renderer/src/components/FollowCTACard.tsx): 마지막 CTA 카드의 프로필 원형 아바타 영역에도 동일 로고 연동

### 4. 원형 배지 흰색 여백 제거 및 재렌더링 검증

- 배지 동그라미 안에 로고가 꽉 차지 않고 둘레에 흰색 링/여백이 노출되는 문제 해결 (아래 트러블슈팅 2 참고)

## 🐛 발생한 문제 & 해결

### 문제 1: `npm run render` 실행 시 `Cannot find package 'vite'` 에러

- **원인**: `apps/card-renderer` 디렉토리에서 최초 의존성 설치(`npm install`)가 진행되지 않은 상태였음.
- **해결**: `apps/card-renderer`에서 `npm install` 실행하여 `vite`, `playwright` 등 필요한 29개 패키지 설치 완료. 이후 렌더링 스크립트 정상 동작.

### 문제 2: 원형 배지 컨테이너와 로고 사이즈가 맞지 않아 둘레에 흰색이 노출되는 문제

- **원인 분석**:
  1. 원본 생성 이미지(1024x1024) 내에 바깥쪽 흰색 여백(여백 폭 ~100px)뿐 아니라 그래픽 자체에도 둘레에 흰색 링(White Ring, 반경 342~372px)이 포함되어 있었음.
  2. CSS의 `.card-mascot-badge`에 `background: #fff`가 지정되어 있어 서브픽셀 렌더링 시 흰색이 비침.
- **해결**:
  1. Python PIL로 중심점(511, 511) 기준 반경 340px(직경 680px)의 순수 주황-코랄 그라데이션 영역을 픽셀 단위로 측정.
  2. 흰색 링과 외부 여백을 완전히 배제하고 680x680 영역만 크롭한 뒤, 4배 슈퍼샘플링 란초스(LANCZOS) 필터로 매끄러운 안티앨리어싱 원형 마스크를 씌운 `logo.png` 생성.
  3. `cards.css`의 배지 컨테이너 배경을 `background: transparent`로 변경하고 `img`에 `border-radius: 50%` 부여.
  4. 재렌더링 결과, 카드 우상단 동그라미 전체에 빈틈없이 100% 꽉 찬 그라데이션 로고로 완벽 출력됨.

## 💡 배운 점 / 메모

- AI 이미지 생성 도구로 제작한 뱃지/스티커 이미지는 시각적으로 원형이어도 캔버스 외곽에 여백 및 스타일링용 흰색 림(border ring)이 함께 생성되는 경우가 많다. 웹 컴포넌트의 고정 규격(예: 130px 원형 배지)에 딱 맞추려면 이미지를 단순히 `object-fit: cover`하는 것보다 실제 유효 그래픽의 픽셀 반경을 정확히 측정하여 크롭하는 것이 가장 마감이 깔끔하다.
- 투명 PNG 포맷과 CSS의 `background: transparent` 조합을 사용해야 고해상도 렌더링 시 안티앨리어싱 경계면에서 흰색 잔상이 남지 않는다.
