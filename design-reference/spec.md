# 카드뉴스 레이아웃 스펙

> 2026-10-18 맛집 → 혜택 주제 전환으로 사진 위주 카드에서 **텍스트 중심 카드**로 바꿨다
> (`_docs/topic-pivot-benefits-plan.md` §6.4). `places/*.png`는 맛집 시절 레퍼런스(seoulhotple 계정)로,
> 공통 요소(워터마크·로고 배지)와 CTA 프로필 위젯 구성만 이어서 쓴다.
>
> 캔버스: 1080 x 1350px (4:5, 인스타 세로형). 구현은 `apps/card-renderer/src/components/`.

## 0. 전 카드 공통 요소

| 요소 | 위치 | 크기/스타일 |
|---|---|---|
| 계정 워터마크 | 좌상단, 여백 32px | 📷 + 핸들, 흰색 굵은 28px (CTA 카드엔 없음) |
| 브랜드 로고 배지 | 우상단, 여백 24px | 원형 배지 지름 130px (`/logo.png`, 원본 `/logos/hotsoozip_logo.svg`) |
| 배경 | 전체 | 사진 없이 그라디언트 + 반투명 원 2개(`.card-pattern`) |
| 칩 | 상단 | 높이 60px 알약형. 흰 바탕(카테고리) / 흰 테두리(상시) / 검정 바탕+노랑 글자(마감 임박) |

**색**: 커버·CTA는 브랜드 그라디언트(코랄 `#ff4d5e` → 오렌지 `#ff9a1f`, 로고와 같은 색).
콘텐츠 카드는 카테고리(보조금24 서비스분야 10종)별 그라디언트이고, 흰 패널 위 강조색(`ink`)과
캡션 바탕(`soft`)도 카테고리를 따른다. 표는 `apps/card-renderer/src/theme.ts`. 고용·창업은 브랜드색.

**글자 넘침**: 정책명 길이가 항목마다 크게 달라서(p50 14자, p99 34자) 글자 크기를 고정하지 않는다.
글자가 들어가는 박스는 `FitText`가 최대→최소 크기 사이에서 줄여 맞추고, 최소로도 넘치면
렌더 스크립트가 실패한다 (잘린 정책명·지원 내용을 내보내지 않기 위해).

## 1. 커버 카드 — `CoverCard.tsx`

**목적**: 이번 회차가 무엇인지(카테고리·건수) + 후킹 문구로 스와이프 유도

- **칩** (위 240px): 카테고리(district 시리즈는 자치구, 예: "동작구") + 시리즈 배지
  (`상시 신청 가능` / `우리 구 혜택` / `마감 임박`)
- **후킹 문구** (위 350px, 높이 640px): `hook_line`을 `\n`으로 나눈 줄. Black Han Sans,
  흰색/크림(#fff3b0) 줄 번갈아, 150px에서 시작해 최소 80px까지 줄인다. 줄바꿈 없음
- **회차 제목** (아래 96px): 흰 알약(높이 104px) 안에 `series_title` 52→30px
  + 그 아래 "혜택 N개 · 옆으로 넘겨보세요 →"

## 2. 콘텐츠 카드 — `ContentCard.tsx`

**목적**: 혜택 1건. 위에서부터 읽으면 "뭐고 → 뭘 주고 → 누가 받나" 순서

- **칩 줄** (위 180px): 카테고리 칩 + 기한 배지 + 오른쪽 `01 / 05`
  - 기한 배지: `period_end`가 null이면 `상시 신청`, 있으면 `generated_at` 기준 `D-n`
    (7일 이내면 마감 임박 스타일), 당일·지난 날짜는 `오늘 마감`
- **흰 패널** (좌우 56px, 둥근 40px, 안쪽 여백 56px)
  - 정책명 `title`: 64→36px, 900, 최대 3줄 높이(max-height 168px)
  - 부제 `subtitle`: 34→26px, 회색, 한 줄
  - "이런 혜택" 라벨 + `benefit`: 60→36px, 900, 카테고리 강조색. **남는 높이를 모두 차지** — 카드에서 가장 큰 정보
  - "이런 분께" 라벨 + `target`: 38→28px, 높이 140px
  - 코멘트 `caption`: 💬 + 카테고리 옅은 바탕 박스, 32→24px, 한 줄
- **푸터** (패널 아래): `출처 · <source_name>` + 오른쪽 "원문 링크는 캡션에 ↓"
  (URL은 길고 이미지에선 못 누르므로 게시물 캡션에 넣는다)

## 3. CTA 카드 — `FollowCTACard.tsx`

**목적**: 팔로우 유도 + 비공식 큐레이션·출처 표기

- **후킹 2줄** (위 280px): `hook_lines` [서브 36px, 메인 50px]. 없으면 생략
- **프로필 위젯** (위 560px): 흰 카드(폭 85%) 안에 로고 아바타 120px + 핸들 36px + 파란 "팔로우" 버튼
  (인스타 프로필 미리보기 재현, 맛집 시절 `cta_2.png` 레퍼런스 구성)
- **마무리 문구** (위 840px): `cta_text`, 40px, `\n` 줄바꿈
- **고정 표기** (아래 72px, 반투명 검정 박스): "비공식 큐레이션 · 신청 전 원문 공고를 꼭 확인하세요"
  + "출처: `<data_source>`". 데이터와 무관하게 항상 넣는다 — 기관 공식 계정 오인 방지 (계획서 §8)
